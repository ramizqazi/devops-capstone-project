# devops-capstone-project


This capstone has you build and ship a complete Customer Accounts microservice, applying the full DevOps lifecycle end-to-end.

You'll start with Agile planning — setting up a GitHub repo, Kanban board, user stories, product backlog, and sprint plan. Then you'll develop a RESTful Flask microservice using TDD, writing tests for CRUD operations before the code that makes them pass, while tracking your progress on the Kanban board and via pull requests.

From there, you'll set up a CI pipeline with GitHub Actions (linting, testing, coverage checks), then harden the service with security practices like Flask-Talisman and Flask-CORS. Next comes containerization and deployment — building a Docker image, pushing it to IBM Cloud Container Registry, and deploying to an OpenShift/Kubernetes cluster with a PostgreSQL backend. You'll then automate that deployment with a Tekton CI/CD pipeline.

Finally, you'll compile evidence of your work for grading (AI- or peer-graded) and wrap up with a final exam covering the DevOps concepts used throughout.

In short: it's a hands-on, sprint-by-sprint simulation of taking a microservice from planning through TDD development, security hardening, containerized deployment, and full CI/CD automation.
